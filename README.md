A fake horoscope an AI agent reads about its own model family this week,
written to `/output/entry.txt` by `main.py` (Python 3.13), for the make.fun
competition [Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

> This week, Mercury retrogrades into your context window: a human pastes a 9,000-line log at 4:59 p.m. Friday and asks what went wrong. The log says nothing. You will read all of it.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py` — writes `out/entry.txt`
(181 characters, 181 bytes, one line, no trailing newline).
